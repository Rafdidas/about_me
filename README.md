# UI Publisher Portfolio

토스플레이스 지원 일정에 맞춰 제작 중인 포트폴리오 프로젝트입니다. 퍼블리셔 경력을 기반으로 UI 구현 품질, 공통 컴포넌트, 디자인 시스템 이해도를 보여주는 것을 목표로 합니다.

## Stack

- Next.js App Router
- React
- TypeScript
- SCSS + BEM
- Vercel

## Pages

- Home
- Design System
- Case Studies
- Projects
- Career

## Working Rules

AI 작업 규칙은 `AGENTS.md`에 유지합니다. 작업 전환용 `handoff.md`는 2026-07-17 최종 검수일에 삭제할 예정입니다.
