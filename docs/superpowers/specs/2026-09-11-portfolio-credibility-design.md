# 포트폴리오 콘텐츠와 신뢰도 개선 설계

## 목적

포트폴리오가 두 경험을 혼동 없이 전달하도록 콘텐츠를 정리한다.

- 실무: 이커머스와 B2B 업무 시스템의 UI 구축·운영, 공통 UI 구현 경험
- 개인 프로젝트: AI를 활용해 개발하고 실제 운영 중인 모니북

회사와 고객사명은 실제 수행 이력의 근거로 유지한다. 실제 화면, 내부 코드, 내부 데이터와 확인되지 않은 성과 수치는 공개하지 않는다.

## 범위

- Home, Case Studies, Design System, Projects, Career의 콘텐츠와 링크를 업데이트한다.
- 모니북 카드에 `money-book` 앵커와 `AI 활용 개발`, `운영 중` 상태를 추가한다.
- Design System과 Admin Table을 가상 데이터 기반 포트폴리오 예시로 표시한다.
- README를 포트폴리오의 목적, 공개 범위, 페이지별 근거와 실행·검증 방법 중심으로 재작성한다.
- 콘텐츠 테스트를 사실 기반 주장과 앵커 연결을 검사하도록 수정한다.

현재 라우팅, 스타일 체계, 공통 컴포넌트의 공개 인터페이스, Admin Table의 필터·정렬·페이지네이션 동작은 유지한다. 실제 업무 시스템 화면이나 새 업무 데모는 만들지 않는다.

## 콘텐츠 원칙

1. 확인된 업무 배경·담당 범위·구현 내용을 우선한다.
2. `5종 이상`, `7개 구조 기준화`처럼 범위나 집계 기준을 설명할 수 없는 수치는 삭제한다.
3. `재사용`은 공유 패키지 여부가 확인되지 않았으므로, 컴포넌트를 구현하고 업무 화면에 적용한 경험으로 표현한다.
4. AI 활용은 모니북의 제작 방식이며, 실무 프로세스나 서비스 내부 기능으로 일반화하지 않는다.
5. `RLS 기반 데이터 보호` 등 확인되지 않은 보안·운영 주장은 게시하지 않는다.

## 페이지별 변경

### Home

- 히어로는 UI Publisher 직무와 6년 이상의 UI 구축·운영 경험을 유지한다.
- 주 행동은 `실무 사례 보기`, 보조 행동은 `AI 활용 프로젝트 보기`로 제공한다.
- 안내 패널은 실무 경험, UI 구현 예시, AI 활용·서비스 운영을 각각 해당 페이지 또는 앵커로 연결한다.
- Design System 미리보기에는 공개된 포트폴리오 예시라는 성격을 밝힌다.
- 첫 번째 프로젝트 카드에서 모니북의 AI 활용 개발·운영 상태를 표시한다.

### Case Studies와 Career

- 기존 앵커와 회사·고객사명은 유지한다.
- 사례는 업무 배경, 담당 범위, 구현 내용 순으로 축약한다.
- 실무 시스템의 비공개 범위와 연결된 UI 예시의 성격을 페이지 상단에 안내한다.
- Career에는 실무 이력만 두고, 개인 프로젝트의 AI 활용 경험은 Projects에서 설명한다.

### Design System

- 상단과 Admin Table에 가상 데이터 기반 포트폴리오 예시임을 안내한다.
- `실무를 재구성한 화면`이라는 표현 대신 업무 화면에서 다룬 UI 흐름을 설명하기 위한 별도 예시로 표현한다.
- 현재 클라이언트 컴포넌트는 검색·필터·정렬·상태 전환처럼 브라우저 상호작용을 담당하고, 순수 데이터 변환은 `src/lib/adminTable.ts`에 둔 구조를 유지한다.

### Projects

- 모니북의 표시 이름을 `모니북`으로 통일하고 제목에 `id="money-book"`을 둔다.
- 카드에는 `운영 중`, `AI 활용 개발`을 텍스트가 있는 배지로 표시한다.
- 서비스와 GitHub 링크를 제공한다.
- 실제 사용 도구·대표 사례·배포 기록은 확인 전까지 추가하지 않는다.

## 데이터와 테스트

`src/data/`의 콘텐츠 객체에 필요한 상태와 표시 이름을 추가한다. 페이지 컴포넌트는 기존처럼 데이터를 렌더링만 한다.

테스트는 다음을 확인한다.

- 모니북의 앵커, 운영 상태, AI 활용 개발 문구와 외부 링크
- Design System 및 Admin Table의 포트폴리오 예시 안내
- Case Study의 기존 앵커 유지
- 근거 없는 숫자 성과와 확인되지 않은 RLS 주장의 부재

## 검증

- `npm run lint`
- `npm test`
- `npm run build`
- 360px와 데스크톱 뷰에서 Home의 버튼, Projects 앵커, 모바일 테이블 카드형 전환을 확인한다.
